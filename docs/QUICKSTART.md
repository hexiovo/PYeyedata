# PYeyedata 快速上手

## 下载并启动

1. 打开 [最新版本下载页](https://github.com/hexiovo/PYeyedata/releases/latest)。普通使用请下载名称含 `windows-x64.zip` 的便携包。
2. 下载同一版本的 `SHA256SUMS.txt`，按其中的校验值核对 ZIP。程序目前未做代码签名。
3. 将 ZIP **完整解压**到本机文件夹，例如 `D:\Apps\PYeyedata`。不要在压缩包预览窗口中直接运行，也不要只复制 EXE。
4. 双击解压目录中的 `PYeyedata.exe`。支持 Windows 10/11 x64；无需单独安装 Python、Qt 或数据库。首次启动会在临时目录解压内置运行环境，请预留磁盘空间。

也可下载同版本的独立 EXE；它更适合临时体验。常规使用建议用 ZIP 版，应用程序、离线说明和许可证材料都在同一目录。

## 先完成一次合成练习

启动后按 **F1** 或选择 **帮助 → 新手入门与文件示例**。通过 **帮助 → 导出练习资料与模板** 获取合成练习文件。导入 `signals-practice.csv` 并加载 `pupil-mean-practice.pyeplan`，核对左瞳孔平均值约为 3.3 mm。此练习只用于熟悉操作，不代表真实设备验证。

开始真实研究前，先整理一份脱敏数据字典：设备和导出版本、真实表头与单位、有效性代码、时间来源、被试/团队 ID、刺激/AOI 信息，以及预先确定的指标、独立单位和统计问题。不要根据数值范围猜单位、眼别、代码含义或被试独立性。

## 文件分别做什么

- 原始 CSV/TSV/TXT/XLSX：实验数据，从“数据导入”页打开。
- 导入配置：保存已核对的源列映射，在“数据导入”页管理。
- `.pyeplan`：分析设置，通过 **文件 → 加载分析方案…** 使用；不包含数据或结果。
- `.pyea`：一次运行的档案，在“结果与追溯”中查看；可否重算取决于档案模式和保留内容。
- 研究配置包：参数台账、映射和单位依据、阶段清单及操作手册；不等同于 `.pyeplan`。

建议先在研究文件夹中建 `input/`（只读源文件）、`converted/`、`exports/` 和 `runs/`。将导出和档案放在项目数据目录，不要覆盖原始文件。

## 用实验设计准备研究配置

Release 附有两种 `pyeyedata-study-config` 文件：

- `PYeyedata-1.0.0-pyeyedata-study-config.md`：单文件版，内含所有指引和 helper 源码，适合连同实验设计、数据字典和脱敏样例一起交给可读取 Markdown 附件的 AI。
- `PYeyedata-1.0.0-pyeyedata-study-config.zip`：目录版，适用于支持安装技能目录的工具；解压后保留原目录结构。

AI 根据实验设计生成的 `.pyeplan` 仍需在匹配版本/源码的 PYeyedata 中通过原生方案校验，并由操作者用真实文件导入和运行前检。结构校验通过不表示数据已就绪、统计假设成立或真实设备的小样本试运行成功。没有匹配的源码/环境时，校验状态应为 `not_run`。

## 出现问题时

先记下当前页面、完整报错和所用输入/设置版本。数据语义或映射不确定时暂停，向数据提供者确认；运行日志可以帮助定位，但不能代替科学判断。`partial`、`unavailable` 或 `failed` 都应保留原状态和原因，不要把缺失结果改成 0。
