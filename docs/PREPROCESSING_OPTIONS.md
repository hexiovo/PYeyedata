# 可选瞳孔预处理

文献检索与方法核对日期：2026-10-30。本轮纳入下述近期文献中可由现有输入支持的三个组件；各项均可单独选择。

## 默认行为与界面

瞳孔速度 MAD 拒绝和眨眼 / 丢失边界遮罩默认关闭。瞳孔插值也默认关闭；用户显式启用后，默认方法为线性。质量页提供三个需要点击“应用所选预设”的入口：关闭瞳孔插值 / MAD / padding、保守短缺口线性插值、研究方法组合。第一个预设只关闭这三项瞳孔处理并重置它们的参数，gaze、低通、基线及其他设置保留。高级方法和参数默认折叠。预设不会自动运行分析，也不会扩大当前的最大缺口秒数或连续缺失采样点上限。

研究方法预设启用 PCHIP、速度 MAD（`n=20`）和边界遮罩（之前 50 ms、之后 150 ms）。它保留用户当前的缺口秒数及采样点上限；遮罩后若缺口超过这两个界限，瞳孔值继续缺失，不会为了补满数据而自动放宽限制。

## 实现规则

- **速度 MAD 拒绝（可选）**：仅用有限、时间递增、明确标记为来源有效且不重复的相邻 pupil 样本计算速度。每个样本的速度是相邻前后可用差分绝对速度的较大值。阈值为 `median(speed) + n × median(abs(speed - median(speed)))`，仅拒绝严格大于阈值的样本。默认 `n=20`。当 MAD 为零时仍按该公式使用中位数阈值；审计标记需要人工复核，并记录实际阈值、样本数和拒绝数。
- **眨眼 / 丢失边界遮罩（可选）**：逐眼种子包含非有限 pupil、明确来源无效 pupil、逐眼眨眼 / 闭眼标记；来源有效性未知时，零值也作为可能的丢失标记。遮罩按秒向前、向后扩展，并在连续支持段内合并重叠范围；不会跨处理分区、非递增时间或超过支持阈值的时间跳跃扩展。
- **插值**：线性方法是显式启用 pupil 插值后的默认方法。线性插值继续使用已有规则：只能在同一处理分区内填补、总缺口时长不超过配置的 pupil 最大秒数、连续缺失样本数不超过上限；不增加新的内部时间间隔判断。PCHIP 需要缺口左右各两个可信来源锚点，并额外要求从左侧 PCHIP 锚点到右侧 PCHIP 锚点之间的每个相邻时间间隔为正且不超过支持间隔阈值。PCHIP 只在锚点范围内计算，不外推；锚点不足或时间支持不连续时保持缺失并输出状态说明。两种方法均保留各自已有的处理分区和缺口上限。
- **有效性和来源**：可选拒绝、遮罩和插值都只影响分析副本。启用方法时，原始 pupil 值保留在 `raw__pupil_left/right`；来源有效性列不被改写。速度拒绝、种子、扩展遮罩和插值各有独立逐行标志。短的拒绝 / 遮罩缺口如果符合现有插值界限，仍可能被线性或 PCHIP 重建；拒绝 / 遮罩标志和原始值继续保留，插值标志说明该分析值是替代值。插值审计列记录实际目标行、使用的锚点行、时间和方法，并将替代值标为派生插值，不赋予观测来源。质量摘要和运行审计分别记录计数、参数、阈值、跳过原因和来源引用。单位沿用输入声明；未知时不推断或制造 pupil 单位。
- **作用范围**：这些开关只处理瞳孔。gaze 计算、来源值和默认行为保持原样。实现没有增加依赖标定的 PSA / 凝视角校正，也没有增加双眼回归填补；是否需要这些步骤取决于设备、标定和研究证据，不能假定普遍有益。

速度 MAD 对采集滤波敏感。启用前请确认设备没有对记录进行在线或保存后滤波；滤波可能抹平速度尖峰。软件不自动判断设备过滤状态。请检查原始轨迹、质量图和逐行标志，并依据实验方案决定是否采用。

## 研究依据与适用边界

下列文献用于说明可选方法及审计原则。PYeyedata 只实现文中列出的瞳孔方法组件，并额外保留连续支持、有效性、缺口边界和来源约束；不声称复现完整论文流程或对所有设备和范式均适用。

1. Ong 等，**A Preprocessing Pipeline for Pupillometry Signal from Multimodal iMotion Data**，*Sensors* 25(15):4737 (2025)。论文描述速度 MAD 与 PCHIP，但其完整工作流还包含其他设备和任务相关步骤；文中示范参数和算法并不构成所有数据的通用默认值。[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC12349379/)，[DOI](https://doi.org/10.3390/s25154737)。
2. **Sensory traits are associated with global differences in the pupillary light reflex waveform in young adults**，*Scientific Reports* (2026)。该研究报告的流程对眨眼 / 跟踪丢失和超范围片段使用 50 ms / 150 ms padding，并使用 PCHIP；本文仅借鉴这两个可选设置，不实现该研究的其他滤波和 PLR 分析步骤。[论文方法](https://www.nature.com/articles/s41598-026-48654-5)。
3. Schwartz 等，**eyeris: A Flexible, Extensible, and Reproducible Pupillometry Preprocessing Framework in R**，*Psychophysiology* 63(8):e70375 (2026)。该工作支持模块化、可追溯的预处理记录。其 EyeLink 使用说明警告，在线或保存样本滤波会削弱基于速度尖峰的 MAD 检测前提；此软件无法自动检测该设备状态。[PubMed 记录](https://pubmed.ncbi.nlm.nih.gov/42590799/)，[作者流程说明](https://eyeris.shawnschwartz.com/articles/complete-pipeline.html)。
