# PYeyedata 1.0.0

## 本次更新

- 新增完整的 `pyeyedata-study-config` 研究配置 skill。它把实验设计整理为参数台账、数据映射/转换计划、原生 `.pyeplan`、统计方法边界、阶段清单和面向零基础主试的操作手册；遇到缺少设备、单位、时间、有效性或独立单位等信息时会明确提出问题并阻断受影响阶段。
- skill 提供目录版和单文件版。单文件版包含全部参考说明和校验工具源码，适合随实验设计和脱敏数据示例一起提供；目录版保留可安装的文件结构。
- 便携 ZIP 现附快速上手、部署/发布文档、研究配置 skill 和第三方许可证。Release 同时提供可单独下载的 skill ZIP/Markdown，以及覆盖全部资产的 `SHA256SUMS.txt`。
- 调整 README、快速上手、部署、接手和发布说明，使下载、校验、解压、练习、配置与部署步骤集中且版本一致。

## 兼容性与验证边界

- 应用版本升至 1.0.0；PRD 版本 0.9、数据契约 1.3.0、科学算法和 `.pyea` / `.pyeplan` 契约未因应用版本号而变化。没有新增运行依赖。
- 随附 41 页中文图解手册未修改，内容版本仍为 0.9.3。
- 本次源码和冻结程序检查、构建环境、精确提交、PE 版本、资源/原生依赖映射及 EXE 哈希以 Release 的 `release-info.json` 和 `SHA256SUMS.txt` 为准。
- 自动检查和合成数据不等于真实眼动设备验证、独立主机安装验收或不同显示器/DPI 科学验收。实验配置结构可加载，也不表示真实数据已导入、统计前提成立或设备小样本试运行成功。
