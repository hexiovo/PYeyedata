# PYeyedata 0.9.6

- Windows 10/11 x64 便携版：下载 ZIP 解压运行，或直接下载 EXE，无需安装 Python。
- 新增 52 项指标：34 项事件分布统计、9 项基于注视事件的 AOI 注视/命中指标、9 项阅读指标，包含首遍阅读时间、Go-past、跳读率和首遍回视率。
- 新增指标保留单位、事件来源、有效性、分子/分母、未知状态与审计信息。严格的 AOI 首次注视独立于原有采样进入时间；未知观察不作未命中。阅读计算需明确的 AOI 顺序、方向与覆盖确认。
- 纳入导入映射预设、逐文件批量队列、质量时间轴、静态图片 AOI 编辑、历史运行比较及缺失原因导航。后台任务和结果筛选显示阶段、已用时间与会话内校准的预计剩余时间。
- 保持数据、`.pyea` 档案及 `.pyeplan` 方案 schema；旧方案只补新增参数的安全 None/False 缺省。个体算法版本更新为 `individual-0.3.0`，隔离旧计算缓存。
- 便携 ZIP 附 `COMMON_METRICS.md` 与 `WORKFLOW_ENHANCEMENTS.md`，分别说明新指标和新工作流。内置 41 页 PDF 内容仍为 0.9.3，新增功能请阅读这两份补充说明。
- 继续提供精确 Git 提交的源码 ZIP、SHA-256 校验和和 `release-info.json`。发布脚本对源码和最终 EXE 各执行三项固定诊断，并校验 PE 版本、内嵌源码/资源哈希及原生组件许可证映射；实际结果以本次 `release-info.json` 为准。

优先使用 `PYeyedata-0.9.6-windows-x64.zip`。开发请克隆仓库，先读 `CODEX_HANDOFF.md`。

本版本未代码签名。固定诊断使用合成数据及离屏 GUI；尚未声明真实设备、干净新主机或原生多屏/DPI 验收。内置指南内容版本为 0.9.3。
