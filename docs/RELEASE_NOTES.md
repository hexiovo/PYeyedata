# PYeyedata 0.9.10

- 导入页内置四个模板：EyeLink Data Viewer 左眼/右眼采样报告、Tobii Pro Lab 传统/带单位表头。支持 TSV 和表格 TXT；应用前仍需核对实际字段、时间单位、眼别与 ID，保留缺失字段及未知有效性，不代表真实设备验证。
- 修复“分析范围”和导入预设下拉列表的宽度、行高与放大字体显示；显式映射的源列不再被别名回退重复分配。
- 工具栏与“帮助”菜单增加“环境检查与依赖安装”：检测 Python、锁定依赖版本、关键模块导入和依赖关系，显示结果、安装日志及停止按钮。源码版可一键修复项目 .venv；EXE 依赖随包内置，检查内置依赖且不启动 pip。安装后需重启。
- 批量分析使用模板前需保存核对后的实际映射。未知来源、同步、设备验证和 AOI 坐标仍需按实际采集另行声明。
- 不修改科学算法、缓存行为、用户数据、.pyea 运行档案或 .pyeplan 方案契约。图解手册内容版本保持 0.9.3。
- 源码与最终 EXE 的固定诊断、PE 版本、内嵌输入哈希、原生依赖核对和 EXE SHA-256 以本次产物 release-info.json 为准。本机交付不代表远端 Release 已发布。

单文件 EXE 和便携包适用于 Windows 10/11 x64。未代码签名；合成离屏检查和本机界面检查不代表真实设备、干净新主机或原生多屏/DPI 科学验收。
