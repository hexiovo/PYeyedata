# PYeyedata 0.9.8

- 单文件 EXE 在解包阶段显示“正在启动，请稍候”画面；主窗口就绪及启动失败时关闭。
- 统计设计页新增 10 个常用预设、简洁/高级视图和收起设置摘要。常用参数有默认值，研究者仍须确认独立性、变量类型和真实列映射。
- 质量页新增可选瞳孔速度 MAD、眨眼/丢失留白和 PCHIP 插值，默认关闭；保留原始有效性、逐行标记、参数及插值锚点来源。已有方案补入安全缺省值。
- 同步启动图、Tcl/Tk 依赖来源与许可证、构建清单及两份方法指南。应用版本为 0.9.8，内置图解 PDF 内容仍为 0.9.3。
- 本次精确提交、源码与最终 EXE 的三项固定诊断、PE 版本、内嵌输入哈希及原生组件核对结果，以产物 release-info.json 为准。
