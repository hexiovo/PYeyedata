# PYeyedata 0.9.7

- 启动进入 Python 初始化后显示中文等待窗口；主界面就绪或启动失败时关闭。单文件 EXE 在 Python 运行前的解包等待尚不包含在此提示内。
- 运行日志移至独立导航页面；数据预览标明用途，无数据时隐藏，释放主工作区。
- 参数说明跟随鼠标、键盘焦点和表格当前项，支持动态添加的参数控件。正常调整参数不再重复显示误导性的失效日志，已有分析仍按原规则失效并重新检查。
- 为 Windows 主窗口绑定应用标识和任务栏图标；源码与冻结版分别使用稳定的 ICO 或 EXE 图标资源。
- 正式入口核对实际模块来源与包搜索路径，拒绝混用旧程序目录；固定诊断保留来源证据。启动辅助模块纳入构建源文件哈希。
- 会话缓存日志说明实际命中、未复用及完整性拒绝原因。没有新增跨启动自动恢复能力；运行档案与分析方案保持各自契约。
- 保留 52 项常见指标及现有工作流增强；科学算法、数据/档案/方案 schema 与依赖版本不变。内置图解 PDF 内容仍为 0.9.3。
- 本次精确提交、源码与最终 EXE 的三项固定诊断、内嵌源码/资源哈希、PE 版本及许可证映射，以包内 release-info.json 记录的实际构建结果为准。

优先使用 PYeyedata-0.9.7-windows-x64.zip，解压后运行 PYeyedata.exe；也可使用单文件 EXE，无需安装 Python。开发先读 CODEX_HANDOFF.md。
