# PYeyedata 0.9.5

- Windows 10/11 x64 便携版：下载 ZIP 解压运行，或直接下载 EXE，无需安装 Python。
- 新增 `setup.cmd`、`start.cmd`、`release.cmd`，统一准备开发环境、启动和发布。
- 提供精确 Git 提交的源码 ZIP、SHA-256 校验和、构建信息和源码/EXE 的固定诊断结果。
- 加入 `AGENTS.md`、`CODEX_HANDOFF.md` 和部署说明，方便新主机上的 Codex 继续开发。
- 纳入 0.9.4 的应用、窗口和任务栏图标；保留 41 页离线图解手册、练习模板、方案与运行档案功能。
- 科学计算逻辑、依赖版本和分析默认参数未变；合成练习左瞳孔均值约为 3.3 mm。

优先下载 `PYeyedata-0.9.5-windows-x64.zip`。开发请克隆仓库，先读 `CODEX_HANDOFF.md`。

本版本未代码签名。固定诊断使用合成数据及离屏 GUI；尚未声明真实设备、干净新主机或原生多屏/DPI 验收。内置指南内容版本为 0.9.3。
