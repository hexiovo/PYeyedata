# PYeyedata 0.9.9

- 优化指标目录：左侧显示选择框和指标名称，右侧显示当前指标的参数说明；搜索与筛选可折叠，不可选择的指标以灰色呈现。
- 调整预设差异窗口，以简体中文列出变化和限制，并明确“应用”和“取消”操作。
- 内置主题预设名称、类别和说明统一使用简体中文；预设 ID、类别键、自定义预设文件和指标可用性规则保持不变。
- 优化组合框文字可读性，兼顾普通窗口、窄窗口和 Windows 150% 缩放。
- 不修改科学算法、缓存行为、用户数据、.pyea 运行档案或 .pyeplan 方案契约。图解手册内容版本保持 0.9.3。
- 源码与最终 EXE 的固定诊断、PE 版本、内嵌输入哈希、原生依赖核对和 EXE SHA-256 以本次产物 release-info.json 为准。本机交付不代表远端 Release 已发布。

单文件 EXE 和便携包适用于 Windows 10/11 x64。未代码签名；合成离屏检查和本机界面检查不代表真实设备、干净新主机或原生多屏/DPI 科学验收。
