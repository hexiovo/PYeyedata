# 常用统计预设

统计设计页提供常用起点，便于快速声明已有后端支持的设计。预设只填写 `DesignSpec` 已有字段，不新增统计公式，也不保证数据满足分析条件；实际方法、独立样本数和阻断原因仍由统计后端返回。

## 预设列表

| 预设 | 起始设计 | 使用前需要核对 |
| --- | --- | --- |
| 仅描述统计 | 不声明推断设计 | 未知设计只产生描述统计。 |
| 独立两组比较 | 连续结果、subject 单位、组间列建议 `between_group` | 两组恰有两个筛选后实际水平时使用 Welch t；若实际有三组及以上，后端自动使用 Welch ANOVA 和 Games–Howell。本预设不会把组数锁为两组。 |
| 独立多组比较 | 与独立两组相同的 `independent` 设计 | 仍由后端按筛选后实际水平数选方法：两组 Welch t，三组及以上 Welch ANOVA 和 Games–Howell。 |
| 配对前后比较 | 连续结果、subject 单位、组内列建议 `condition` | 同一单位的两个条件必须可一一配对；三个及以上条件改用重复测量设计。 |
| 单因素重复测量 | 连续结果、subject 单位、组内列建议 `condition` | 核对条件数、各单位重复次数和完整性；后端按真实结构路由。 |
| 被试随机截距 LMM | 连续结果、subject 单位、`subject_intercept` 模板 | 需要重复观测；预设不增加协变量或绩效目标。 |
| Pearson 相关 | 连续结果、subject 单位 | 选择绩效列并声明与 metric 表的一对一连接键；逐列声明真实绩效类型。 |
| Spearman 相关 | 连续结果、subject 单位、Spearman 估计目标 | 等级绩效需声明为 ordinal；重复观测 Spearman 当前不支持。 |
| 被试内重复 Pearson | 连续结果、subject 单位 | 需要每个独立单位有重复观测，并明确绩效列和连接键；重复 Spearman 不支持。 |
| 独立团队比较 | 连续结果、team 单位 | 填写真实团队 ID 列，确认团队间独立并写明依据。pair 行不能作为独立团队；团队 pair 聚合还需高级设置中的成员映射。 |

独立两组和多组预设是同一后端设计的不同起始说明。筛选水平、缺失和完整观测可能改变实际组数，方法只按后端保留的真实水平选择。其它方法的适用条件及已实现边界见 [`../pyeyedata/STATISTICAL_METHODS.md`](../pyeyedata/STATISTICAL_METHODS.md)。

## 应用与核对

先从下拉框选择预设，再按“应用预设”。应用会设置设计类型、连续结果声明和分析单位；列名只是可编辑建议，默认建议沿用 schema 中的 `subject_id`、`between_group` 和 `condition`。团队设计不会猜团队列。

应用预设不会自动勾选独立性确认、生成依据说明、填写单位或选择绩效数据。它会清除此前设计遗留的筛选水平、协变量、模型比较设置和绩效列；已有被试、session、trial 等身份列声明只在仍适用时保留。每次切换后都要按当前数据重新核对。

简单视图只显示当前设计相关的字段。勾选“显示全部设计字段与高级统计选项”可查看完整配置。收起时的非默认字段和选项会在页面摘要中列出，值仍保留。加载 `.pyeplan` 或手动修改设计会按自定义设置显示，不会被误认为已选择某个预设。

当前默认使用探索性 BY 多重比较校正、95% 置信区间和固定的 5,000 次 Bootstrap；随机种子固定为 20261011。确认性分析默认 Holm；只有明确说明 BH 的依赖条件有依据时才使用 BH。高级页显示这些锁定值和全部可配置选项。

运行前请检查：

- 结果确实是连续量；本后端不会把二元、计数、边界比例或删失结果强转为连续。
- 每个 ID、组别、条件、团队和绩效列都对应当前真实数据；默认名称不会自动映射。
- 实际独立单位与重复 / 共享结构符合所选设计；如确认独立性，填写研究者自己的依据。
- 相关分析的绩效列、连接键和逐列类型明确；后端会检查连接唯一性、缺失和有效观测。
- 独立组的实际保留水平数、重复设计的条件覆盖及完整观测满足方法要求。

应用预设不运行分析。完成上述核对后，使用“检查可用条件”；正式方法、状态、N、效应和区间以本次后端结果及审计为准。
